# Zsh для SynapseOS

Пакет собирает Zsh 5.9.2 с musl и статически связывает терминальную библиотеку
из публичного SDK. Редактор строки и дополнение команд включаются в основной
исполняемый файл. Пакет не заменяет `/bin/sh` и Bash

```sh
make zsh JOBS=2
```

Пакет входит в редакции Desktop и Extended. Выберите zsh в `settings`, пункт
«Оболочка консоли», или выполните `settings --set Boot.DefaultShell /bin/zsh`
Новый терминал Weston использует выбранную оболочку. Для текущей консоли выбор
применяется после нового входа или перезагрузки. `/bin/sh` и Bash остаются доступны

Общий `/etc/zshrc` задаёт историю команд, Tab-дополнение, исправление опечаток
в именах команд и цветное приглашение для интерактивного сеанса

В отдельной видимой KVM-VM с ядром 0.1.948 проверены запуск, `source`,
встроенные модули `zsh/zle` и `zsh/complete`, `compinit`, дополнение имени файла
по Tab и вызов предыдущей команды из истории стрелкой вверх

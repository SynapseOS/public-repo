# glibc для Linux ABI SynapseOS

Пакет предоставляет динамический загрузчик и библиотеки GNU C Library для x86_64.
Поддержка экспериментальная: наличие пакета не означает совместимость со всеми
приложениями glibc или полную реализацию Linux ABI ядром.

Исходник: ветка `release/2.44/master`, коммит
`045c51476c7abf6144815a4db44f51a118b4cb3e` из
[зеркала GNU Toolchain](https://gitlab.com/gnutools/glibc).
SHA-256 закреплённого архива:
`5894b65628630090f3267df50d2cfb7edc700daf75fb91df7d881d5eb4e327f7`.
[Публичный профиль зеркала](https://github.com/gnutools/glibc) называет его
копией исходного репозитория Sourceware. Прямое сравнение с Sourceware Git
в этой среде не выполнено из-за защиты сайта. Код архива и контрольная сумма
проверены отдельно.

В исходнике проверено наличие исправлений `GLIBC-SA-2026-0022` и `0023`
в `elf/dl-load.c`, а также `GLIBC-SA-2026-0015` в `libio/fileops.c`.
`GLIBC-SA-2026-0024` затрагивает оптимизацию Power8, которую пакет x86_64
не собирает. `nscd` отключён при конфигурации. Это проверка известных
на 21.10.2026 исправлений, а не утверждение об отсутствии других уязвимостей.

Сборка выполняется командой `make glibc SDK=<путь-к-SDK>` из корня репозитория.
Нужны GCC, GNU make, `bsdtar`, `jq` и проверяемый архив исходников. Рецепт
использует заголовки Linux хоста для сборки. Пакет устанавливает runtime-файлы
в `/lib`, включая загрузчик `/lib/ld-linux-x86-64.so.2`, и лицензии в
`/usr/share/licenses`. Инструментальная цепочка, заголовки для разработки,
локали и полный набор модулей glibc в пакет не входят.
Отладочные символы runtime-библиотек снимаются при упаковке, динамические
символы и сведения о версиях символов сохраняются.

Проверенный пакет получен командой из корня репозитория:

```sh
PATH=/tmp/glibc-port-study/host-tools/usr/bin:/tmp/synapse-bench-20261021/host-tools/root/usr/bin:/usr/bin:/bin \
LD_LIBRARY_PATH=/tmp/glibc-port-study/host-tools/usr/lib/x86_64-linux-gnu \
make glibc JOBS=4 BUILD_ROOT=/tmp/glibc-port-build OUT=/tmp/glibc-port-out \
    SDK=/tmp/synapse-bench-20261021/sdk
```

Пути `/tmp` относятся к тестовой машине, в другой среде нужны свои SDK,
`bsdtar` и инструменты сборки.

Динамический тест glibc 2.44.0-r3 на SynapseOS 0.1.947 прошёл: запуск, TLS,
pthread/futex, файл и TCP, код завершения 0. Результат относится к этому
малому тесту и не подтверждает работу произвольных приложений glibc.

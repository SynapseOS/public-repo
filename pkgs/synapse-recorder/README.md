# Synapse Recorder

В Desktop откройте «Запись экрана» или запустите `recorder gui`. Для Cloud и Tiny команда `recorder tui` открывает панель в терминале. Для фоновой записи и сценариев используйте `recorder record`. Для графической версии нужны пакеты `synapse-recorder` и `synapse-recorder-desktop`. Консольной версии достаточно первого.

## Запись

```sh
recorder record desktop.mp4 --seconds 60 --fps 30 --clock
recorder record region.mkv --region 100,60,800,600 --text "Build review"
recorder shot desktop.png
recorder record camera.avi --camera /dev/video0 --mode 0 --seconds 10
recorder record lesson.mp4 --pip /dev/video0 --pip-width 25 --logo logo.png --audio system
```

Видеодорожка по умолчанию использует H.264. Для MPEG-4 Part 2 укажите `--codec mpeg4`. Доступны контейнеры MKV, MP4 и AVI, частота от 1 до 60 кадров/с и целевой битрейт от 1 до 100 Мбит/с. H.264 округляет нечётную сторону области вверх до чётного числа пикселей. Скорость кодирования зависит от процессора. При пропуске кадров запись сохраняет время их захвата. Новая запись требует свободного имени файла.

Рабочий стол labwc захватывается через Wayland с курсором, включая другие приложения и полноэкранные игры на выбранном рабочем столе. Текущая реализация использует первый выход композитора. `--screen fb` выбирает кадровый буфер консоли. В Cloud нужен виртуальный дисплей с `/dev/fb0`; на машине с одной последовательной консолью доступна запись с камеры.

Камера должна предоставлять устройство UVC с MJPEG или YUY2. Укажите путь из вашей системы. Параметр `--mode` выбирает индекс режима UVC. Наложение камеры находится внизу справа, логотипа внизу слева. Для прозрачного логотипа используйте PNG с альфа-каналом. Снимки можно сохранять в PNG, JPEG и BMP.

## Управление

В TUI клавиша R начинает запись, P ставит на паузу или продолжает, C сохраняет отдельный кадр, S завершает файл. В Desktop доступны те же действия с плавающей панели. «Выделить область» позволяет обвести мышью часть рабочего стола. «Перо» включает рисование поверх рабочего стола. Enter закрепляет рисунок и возвращает ввод приложениям. Повторное нажатие «Перо» снимает рисунок. В окне студии F9 начинает или завершает запись, F10 сохраняет снимок. В обновлённой конфигурации labwc Super+F9 переключает паузу, Super+F10 сохраняет снимок, Super+F11 завершает запись из другого окна. Снимки во время записи получают имя вида `lecture.mp4.0001.png`.

Для управления записью из другого терминала того же пользователя включите `--controls`. Графическая и текстовая панели включают его автоматически.

```sh
recorder record lecture.mkv --controls --delay 5 --seconds 300
# Из другого терминала
recorder pause
recorder snapshot
recorder pause
recorder stop
```

Ctrl+C завершает запись с сохранением. При внезапном отключении питания незавершённый MP4 может потребовать восстановления.

## Звук

`--audio system` читает монитор выходного устройства PulseAudio. `--audio mic` читает источник по умолчанию, `--audio both` смешивает их поровну. Нужны запущенный PulseAudio и рабочий источник. При выборе микрофона проверьте, что источником по умолчанию выбран физический вход. Консольная запись по умолчанию идёт без звука. Для автоматических стендов `--audio /путь/поток.pcm` принимает PCM S16LE, стерео, 48 кГц. Звуковая дорожка сохраняется в AAC.

## Сборка

Из корня публичного репозитория выполните `make synapse-recorder synapse-recorder-desktop`. Рецепт проверяет SHA-256 исходников FFmpeg и minih264. Зависимости Qt и Wayland используются только в настольном пакете. Команда `recorder --help` выводит синтаксис консольной версии.


В меню Desktop в разделе «Мультимедиа» доступны три программы. «Запись экрана» сохраняет MP4, MKV и AVI. В списке источников можно выбрать монитор или отдельное окно. Логотип PNG и изображение с камеры можно включить одновременно. Во время записи на системной панели виден индикатор REC.

«Камера» показывает подключённые камеры, открывает просмотр по кнопке и сохраняет снимки в «Изображения», а видео MP4 в «Видео». «Диктофон» записывает микрофон в стерео WAV, 48 кГц, в каталог музыки. Запись начинается по кнопке «Начать запись».

В терминале команда `recorder sources` выводит имена мониторов и идентификаторы открытых окон текущего сеанса Wayland. Для выбора используйте `--monitor ИМЯ` или `--window ID`, для скрытия указателя добавьте `--hide-cursor`. Команда `recorder voice interview.wav` записывает микрофон до Ctrl+C.

# LLVM для Qt

```sh
make qt6-llvm-runtime JOBS=2
```

Частный LLVM 20.1.8 и его зависимости для библиотек Mesa, которые загружает Qt
Файлы находятся в `/usr/lib/qt6/llvm`, системный Mesa не заменяется
Отдельный пакет нужен из-за ограничения размера одного `.spkg` в 256 МиБ

Используются закреплённые musl APK, их SHA-256 и лицензии перечислены в `assets.json`
Это упаковка готового runtime, а не компиляция LLVM из исходников
Установочные сценарии Alpine не выполняются, libc из APK не поставляется
Сведения `.PKGINFO` и список источников сохраняются в `/usr/share/licenses/qt6-llvm-runtime/`

Пакет собран на хосте, гостевая загрузка проверена вместе с Qt и Telegram в KVM
Это не подтверждает работу аппаратного ускорения

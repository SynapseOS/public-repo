# LuaSocket

Пакет содержит LuaSocket 3.1.0 для Lua 5.5: нативные модули `socket.core`,
`mime.core` и Lua-файлы библиотеки. Интерпретатор Lua устанавливается отдельно

Сборка из корня публичного репозитория:

```sh
make luasocket
```

Проверка исполнения выполняется отдельно в SynapseOS, наличие пакета не является
подтверждением прохождения всех сетевых сценариев

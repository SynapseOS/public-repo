# Рецепты пакетов

Сборка всех пакетов из корня репозитория:

```sh
make all JOBS=4
```

Один пакет и его зависимости:

```sh
make sqlite
make -C pkgs netsurf
make -C pkgs/mindustry-desktop
```

Список целей: `make list`. Проверка рецептов: `make check`
Требования к хосту, устройство SDK и CI описаны в [корневом README](../README.md)

`port.json` хранит закреплённые URL и контрольные суммы, `manifest.json` задаёт
пакет и зависимости исполнения. Специальные шаги находятся в `recipe.sh`
Патчи upstream применяются с `--fuzz=0`, исходные архивы проверяются по SHA-256
Python-сборщики заменены Makefile и shell-рецептами

Обычные порты собираются статически с musl, графика и JNI используют общие
библиотеки musl. Библиотеки glibc хоста не должны попадать в целевые пакеты
Архивы создаются в `out/` относительно корня репозитория
Успешная компиляция не является результатом гостевого теста

# 3x-ui и Xray

```sh
setup install 3x-ui
service start 3x-ui
service status 3x-ui
```

После установки служба включена для последующих загрузок. Панель доступна
на самом сервере по адресу `http://127.0.0.1:2053/`. Сервер подписок при
первом запуске отключён. Для удалённого доступа используйте SSH с локальным
пробросом порта: `ssh -L 2053:127.0.0.1:2053 user@server`.

Вход и пароль генерируются в первый раз. Найдите строку `Username:` в
`/var/lib/3x-ui/log/panel.log` от имени root и смените пароль после входа.
База с настройками и входящими подключениями находится в
`/var/lib/3x-ui/db/x-ui.db`. Храните её резервную копию перед обновлением.

`/bin/3x-ui setting -show` показывает параметры панели. Обновляйте панель и
Xray через `setup`, затем перезапускайте службу командой
`service restart 3x-ui`. В пакет входят стандартные базы GeoIP и GeoSite.

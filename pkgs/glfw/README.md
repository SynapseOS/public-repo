# GLFW

Пакет собирает GLFW 3.4 для Wayland. В оконном режиме `libdecor` из пакета
`weston` рисует заголовок и кнопки управления. Патч заменяет выделение места
для общего буфера через `posix_fallocate` на `ftruncate`, поскольку текущая
реализация SynapseOS не поддерживает этот вызов для такого файла

Для Minecraft 1.20.4 задайте Java свойство
`-Dorg.lwjgl.glfw.libname=/usr/lib/libglfw.so.3` перед именем главного класса
Иначе LWJGL распакует собственную библиотеку GLFW, у которой в тестовой сборке
не работают кнопки окна. Проверены меню игры, вход в мир, движение камеры и клики
в видимой QEMU. Клиент Minecraft и ресурсы Mojang в пакет не входят

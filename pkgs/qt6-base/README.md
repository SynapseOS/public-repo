# Qt 6 для SynapseOS

```sh
make qt6-base JOBS=2
```

Первый этап порта Qt 6.11.1: закреплённые библиотеки musl и тестовое приложение
`qt6-smoke`, которое собирается из `smoke.cpp` компилятором SynapseOS
Qt и его зависимости на этом этапе берутся из APK, полная сборка Qt из исходников не реализована
Версии, SHA-256, лицензии и исходные коммиты Alpine перечислены в `assets.json`
Пакеты с обновлениями Alpine edge могут удаляться upstream, для долгосрочного выпуска
нужно закрепить доступное хранилище архивов или перейти на сборку из исходников

Библиотеки изолированы в `/usr/lib/qt6/runtime`, плагины находятся в `/usr/lib/qt6/plugins`
Системный Mesa и библиотеки Weston не заменяются
Используются адаптированные Wayland и XKB из Weston SynapseOS
Отдельный LLVM поставляется пакетом `qt6-llvm-runtime`
`qt6-wayland` добавляет модуль для отображения окон через Weston

В гостевой ОС сначала запустите `weston`, затем из его терминала:

```sh
qt6-smoke
qt6-smoke --self-test
```

Проверка `--self-test` должна вывести `QT_SMOKE_STARTED`, затем `QT_SMOKE_PASS`
Она проверяет создание окна, ошибки рисования и срабатывание таймера, но не заменяет ручную проверку
русского ввода, курсора, колеса мыши, масштабирования и буфера обмена
На хосте тест с `QT_QPA_PLATFORM=offscreen` и библиотеками musl проходит
В отдельной KVM VM с ядром 0.1.912 проверка прошла, окно Widgets отображалось в Weston
Для этого ядру потребовались корректный отказ O_TMPFILE, абстрактные сокеты AF_UNIX,
ожидание дочернего процесса с WNOWAIT и обработка повторного connect
На более старом ядре запуск не поддерживается

Для семафоров Qt требуется ядро не ниже 0.1.915 с операцией `FUTEX_WAKE_OP`
На 0.1.912 простые проверки окна проходили, но ожидание нескольких фоновых задач зависало

Дополнительные проверки в гостевой ОС:

```sh
qt6-shm-probe
qt6-local-socket-probe
qt6-wait-probe
qt6-process-probe
qt6-network-probe
```

Все пять проверок прошли на ядре 0.1.912
Сетевая проверка ожидает HTTP-сервер на хосте QEMU, адрес `10.0.2.2:18088`
Без этого сервера ошибка подключения ожидаема и не проверяет доступность Telegram

Лаунчер выбирает Wayland и программную отрисовку по умолчанию
Явно заданные `QT_QPA_PLATFORM`, `QT_QUICK_BACKEND` и параметры отображения сохраняются
Для загрузки библиотек используется отдельный `LD_LIBRARY_PATH` дочернего процесса
Общий каталог сокетов Weston по умолчанию `/tmp/weston-runtime`, экран `wayland-1`

Установочные сценарии Alpine не выполняются, libc из APK не поставляется
Сведения `.PKGINFO` и список источников сохраняются в `/usr/share/licenses/qt6-base/`

# Weston

```sh
make weston JOBS=4
```

Пакет содержит Weston 13.0.3 с backend для framebuffer и ввода SynapseOS
Backend передаёт относительное движение для приложений, захватывающих указатель
В пакет входит libdecor с Cairo для клиентского оформления окон Wayland
Wayland client/cursor и карты клавиатуры поставляются отдельными пакетами
Они собираются той же целью автоматически

В SynapseOS нужен интерфейс ядра версии не ниже 0.1.907
Запуск: `weston`. Панель Desktop и Extended содержит меню приложений, терминал,
графические настройки, файловый менеджер и Mindustry. Если Weston установлен отдельно от этих программ,
соответствующие кнопки не смогут их запустить
Новые окна терминала используют `Boot.DefaultShell` из `/etc/settings.ini`
Выбор через `settings` применяется без перезапуска Weston, открытые окна не меняются
Переключение окон, включая свёрнутые: Alt+Tab
Одиночное нажатие Super открывает меню программ после получения события клавиши
от ядра. PS/2 и USB передают обе клавиши Super через SynAPI в Weston.
Все открытые окна появляются на верхней панели. Нажатие на название
поднимает окно или возвращает его из свёрнутого состояния
Из терминала Weston также можно запускать `weston-simple-shm` и
`java -jar Mindustry.jar`
Возврат в консоль: Ctrl+Alt+Esc
Снимок экрана: Print Screen. Ctrl+Alt+S также работает. PNG по умолчанию сохраняется в домашнем каталоге
с именем `wayland-screenshot-ДАТА_ВРЕМЯ.png`. Запуск `weston-screenshooter`
из терминала Weston отклоняет по правилам доступа к захвату экрана

На VirtIO GPU разрешение можно изменить в программе `settings`, пункт
«Разрешение экрана», и сохранить клавишей `S`. То же действие из терминала:
`settings --set Display.Resolution 1280x720`. Weston применяет изменение в
текущем сеансе без перезагрузки. Значение `auto` возвращает исходный режим.
Если видеодрайвер не предоставляет `SYN_FB_MODESET`, программа отклоняет
изменение разрешения.

На VirtIO GPU с `/dev/dri/renderD128` Weston автоматически выбирает GL-рендерер Mesa
и VirGL. При отсутствии render-узла используется программный Pixman
Вывод GL-кадра на `/dev/fb0` пока требует чтения пикселей обратно в память CPU
Используется один экран XRGB8888, масштаб 1
DRM/KMS и Xwayland отключены. Тема курсора Breeze общая для приложений,
раскладки us/ru переключаются через Alt+Shift
Экранная клавиатура отключена настройкой `[input-method] path=` в `weston.ini`
Часы панели показывают дату и время как `ДД.ММ.ГГГГ ЧЧ:ММ` в 24-часовом формате
Часовой пояс по умолчанию задан как `Europe/Moscow` (UTC+3) в `settings.ini`
Сборка пакета не заменяет проверку отображения и ввода в гостевой ОС

Адаптации Wayland хранятся в `patches/` и `*.inc`
Реализация локальных сокетов ядра в этот репозиторий не входит

Обои по умолчанию: `/usr/share/backgrounds/synapse/Desktop.png`.
Дополнительные варианты: `Desktop-pattern.png` и `Desktop-pattern-alt.png`
в том же каталоге. Для выбора можно изменить `background-image` в
`/etc/xdg/weston/weston.ini` и перезапустить Weston. Значок меню установлен
из `/usr/share/weston/synapse-logo.png`. Для настроек используется отдельный
`/usr/share/weston/settings-icon.png`.

# SDK публичных пакетов

Здесь находятся исходники musl, нативной пользовательской библиотеки,
общих библиотек и приложений, необходимых пакетным рецептам
Сборка SDK выполняется автоматически целью `make sdk`, результат хранится в `.sdk`
Исходное дерево `sdk/` не используется как каталог объектов
Все исходники нативных программ хранятся в `sdk/apps/apps`, libc в
`sdk/apps/musl`, пользовательская библиотека в `sdk/apps/synlibc`
Общие библиотеки находятся в `sdk/apps/libs` и `sdk/apps/apps/common`

```sh
make native JOBS=4
make native APPS="init/ sh/ ip/ qemu-ga/ monitoring/" JOBS=2
```

Результаты: `.sdk/apps/apps/apps-bin`. Цель `all` также собирает нативные программы
Для сборки не требуется дерево ядра. Утилита firewall использует только публичный
интерфейс управления, реализация фильтра ядра сюда не входит
Рецепты отдельных портов продолжают формировать архивы в `out`

# Системные настройки

Запустите `settings` в терминале. Стрелки влево и вправо переключают разделы.
На вкладке Wi-Fi можно включить адаптер, просканировать сети, выбрать сеть и
ввести пароль. Имя сети и пароль сохраняются в `/etc/network/wifi.conf` с
правами `0600`. Для автоматического повторного подключения включите службу
`wifi` командой `service enable wifi`.

# Wi-Fi

Утилита `wifi` управляет интерфейсом `wlan0` через `/dev/wifi`. Для работы нужен
драйвер, который поддерживает эту версию интерфейса. Без него команда сообщит,
что устройство отсутствует.

```sh
wifi scan
wifi connect "Имя сети" "пароль сети"
wifi status
wifi disconnect
wifi off
wifi on
```

После подключения утилита сохраняет профиль в `/etc/network/wifi.conf` с правами
`0600`. Для повторного подключения при запуске системы используйте `wifi auto`
в службе автозапуска. Пароль хранится локально в конфигурации, поэтому доступ к
файлу должен оставаться ограниченным.

```sh
service enable wifi
service start wifi
```

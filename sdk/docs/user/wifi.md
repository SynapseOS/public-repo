# Wi-Fi

Утилита `wifi` управляет интерфейсом `wlan0` через `/dev/wifi`. Для работы нужен
драйвер, который поддерживает эту версию интерфейса. Без него команда сообщит,
что устройство отсутствует.

```sh
wifi scan
wifi connect "Имя сети" --ask
wifi status
wifi disconnect
wifi off
wifi on
```

На Raspberry Pi 3B+ команда без указания адаптера выбирает подключённый USB-адаптер,
затем встроенный. Укажите адаптер для работы с двумя сетями одновременно.

```sh
wifi usb scan
wifi usb connect "Имя сети" --ask
wifi onboard status
```

Для выбранных адаптеров профили сохраняются отдельно в `/etc/network/wifi-usb.conf`
и `/etc/network/wifi-onboard.conf`. В графических настройках откройте вкладку Wi-Fi,
выберите адаптер и нажмите «Сканировать». Пароль вводится только на плате.

Для общего устройства `/dev/wifi` утилита сохраняет профиль в `/etc/network/wifi.conf` с правами
`0600`. Для повторного подключения при запуске системы используйте `wifi auto`
в службе автозапуска. Пароль хранится локально в конфигурации, поэтому доступ к
файлу должен оставаться ограниченным.

```sh
service enable wifi
service start wifi
```

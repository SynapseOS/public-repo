# Управление Bluetooth

Утилита `btctl` управляет адаптерами Bluetooth через устройства
`/dev/bthci0`, `/dev/bthci1` и так далее. Устройства создаёт модуль
`usb-bt`, который подхватывает адаптеры класса Bluetooth USB transport
(интерфейс `e0/01/01`): донглы CSR8510 и другие стандартные контроллеры.

```sh
btctl info          # сведения об адаптере и контроллере
btctl up            # включить приём и видимость
btctl down          # выключить приём
btctl reset         # сброс контроллера
btctl scan          # пассивный поиск устройств Bluetooth LE
btctl inquiry       # активный опрос классических устройств
```

Дополнительные ключи:

- `--dev PATH` выбрать устройство вместо `/dev/bthci0`
- `--name NAME` задать видимое имя адаптера при `up`
- `--time SEC` длительность поиска, по умолчанию 8 секунд
- `--speaker` выставить класс устройства «громкоговоритель»
- `--headset` выставить класс устройства «гарнитура»

После `btctl up --speaker` компьютер виден телефонам как колонка,
после `btctl up --headset` как гарнитура с микрофоном. Приём звука
требует профилей A2DP/HFP, которые подключаются отдельно.

Состояние модуля смотрите в `/proc/usb-interfaces` и `dmesg`,
строки `usb-bt`.
